Homogeneous Equation Solution Tree

A guide to first-order linear differential equations.

  • Standard form y′ + P(x)y = 0
    Rearrange the equation on an interval where the coefficients are defined.

    • Special case

      Check y = 0 It is a solution of the equation and is included in the general solution.

    • For y ≠ 0

      Separate variables dy / y = −P(x) dx
      • Integrate both sides ln |y| = −∫ P(x) dx + C
        • Solve for y and verify the result y = C · e−∫P(x)dx
          The constant C ∈ ℝ; the formula also includes the zero solution.
