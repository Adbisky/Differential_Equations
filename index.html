Drzewo rozwiązywania równań jednorodnych

Schemat dla liniowego równania różniczkowego pierwszego rzędu.

  • Postać standardowa y′ + P(x)y = 0
    Uporządkuj równanie na przedziale, na którym współczynniki są określone.

    • Przypadek szczególny

      Sprawdź y = 0 Jest rozwiązaniem równania i należy do rozwiązania ogólnego.

    • Dla y ≠ 0

      Rozdziel zmienne dy / y = −P(x) dx
      • Scałkuj obie strony ln |y| = −∫ P(x) dx + C
        • Wyznacz y i sprawdź wynik y = C · e−∫P(x)dx
          Stała C ∈ ℝ; wzór obejmuje też rozwiązanie zerowe.
